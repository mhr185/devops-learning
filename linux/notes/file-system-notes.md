## Commands I used and what they do

 ```bash
mkdir -p /linux/notes # the make directory command creates a directory, adding -p creates a nested directory.
cp git-basics.md file-system-notes.md # copy file command, helps copy previous notes so I can use the structure.
mv git-basics.md /linux # moves a file to a different directory, can also be used to rename files.
cd linux/notes # change to a target directory, probably one of my most used and powerful commands.
```
